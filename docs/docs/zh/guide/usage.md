# 使用指南

本文档详细介绍 Rin 博客系统的各项功能使用方法。

## 评论功能

### 发表评论

1. 在文章页面底部找到评论输入框
2. 输入评论内容
3. 点击"提交"按钮发布评论

:::tip
如果未登录，您需要先通过 GitHub OAuth 登录才能发表评论。
:::

### 删除评论

您可以删除自己发表的评论，管理员可以删除任何评论。

**删除步骤：**

1. 在评论右侧找到"更多"按钮（三个点图标 ⋯）
2. 点击后会出现操作菜单
3. 点击删除图标（垃圾桶图标）
4. 在确认对话框中确认删除操作

:::warning 注意
删除评论后无法恢复，请谨慎操作。
:::

**权限说明：**
- 普通用户：只能删除自己发表的评论
- 管理员：可以删除任何用户的评论

## 文章管理

### 创建文章

1. 点击页面顶部的"写作"按钮
2. 在编辑器中撰写文章内容，支持 Markdown 格式
3. 设置文章标题、标签等信息
4. 点击"发布"按钮发布文章

### 编辑文章

1. 进入文章详情页
2. 点击右上角的编辑图标（铅笔图标）
3. 修改文章内容
4. 点击"更新"按钮保存修改

### 删除文章

1. 进入文章详情页
2. 点击右上角的删除图标（垃圾桶图标）
3. 在确认对话框中确认删除操作

:::warning 注意
删除文章后无法恢复，文章相关的所有评论也会一并删除。
:::

### 文章置顶

管理员可以将重要文章置顶显示：

1. 进入文章详情页
2. 点击右上角的置顶图标
3. 置顶后的文章会显示在首页列表顶部

### 文章别名

您可以为文章设置自定义 URL 别名，例如 `https://yourblog.com/about`：

1. 在编辑文章时，找到"别名"设置项
2. 输入自定义别名（只能包含字母、数字、连字符）
3. 保存后即可通过自定义 URL 访问

### 隐私设置

您可以将文章设置为"仅自己可见"：

1. 在编辑文章时，找到"可见性"设置
2. 选择"仅自己可见"
3. 该文章将不会出现在公开列表中，只有您登录后才能查看

### 不列出文章

如果您不希望某篇文章显示在首页列表中，但希望通过直接链接访问：

1. 在编辑文章时，找到"列出"选项
2. 取消勾选"在首页显示"
3. 文章将不会出现在首页，但仍可通过 URL 直接访问

## 图片上传

### 上传方式

支持两种图片上传方式：

1. **拖拽上传**：直接将图片文件拖拽到编辑器中
2. **粘贴上传**：复制图片后，在编辑器中按 Ctrl+V（或 Cmd+V）粘贴

上传成功后，系统会自动生成图片链接并插入到编辑器中。

## 标签功能

### 添加标签

在编辑文章时，可以添加标签：

1. 在文章内容中输入标签，格式：`#标签名 #标签名2`
2. 系统会自动解析并展示为标签
3. 读者可以通过标签筛选相关文章

## 友情链接

### 添加友链

管理员可以添加友情链接：

1. 进入设置页面
2. 找到"友情链接"部分
3. 填写友链信息（名称、描述、头像、URL）
4. 点击"添加"按钮

系统会每 20 分钟自动检查友链的可访问状态。

## 时刻动态

类似微博的短动态功能：

1. 点击"时刻"菜单
2. 在输入框中输入动态内容
3. 点击"发布"按钮

时刻支持 Markdown 格式，适合发布简短的想法和动态。

## Webhook 通知

如果配置了 Webhook URL，当有新评论时，系统会自动发送通知到指定的 Webhook 地址。

配置方法请参考 [环境变量配置](/zh/env)。

## 常见问题

### 如何成为管理员？

系统中第一个通过 GitHub OAuth 登录的用户会自动成为管理员，后续用户均为普通用户。

### 本地草稿保存在哪里？

本地草稿保存在浏览器的 localStorage 中，不同文章的草稿互不干扰。

### 评论需要审核吗？

不需要，评论会立即发布。管理员可以事后删除不当评论。

### 支持哪些 Markdown 语法？

支持标准 Markdown 语法，包括：
- 标题、列表、链接、图片
- 代码块（支持语法高亮）
- 表格
- 引用块
- 等等

### 图片存储在哪里？

图片存储在您配置的 S3 兼容存储中（如 Cloudflare R2）。具体配置请参考 [环境变量配置](/zh/env)。
